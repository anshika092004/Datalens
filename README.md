# 🔍 DataLens

DataLens is an interactive **Data Science and Machine Learning platform** built with Streamlit. It allows users to upload a dataset, explore and clean the data, perform exploratory data analysis, generate visualizations, and apply machine learning models — all through an easy-to-use web interface.

## 🚀 Live Demo

[https://datalens-platform.streamlit.app/](https://datalens-platform.streamlit.app/)

---

## ✨ Features

### 📊 1. Data Overview

- Upload CSV datasets directly through the application
- View dataset dimensions
- Preview the dataset
- Inspect column names and data types
- View descriptive statistics

### 🧹 2. Data Cleaning & Preprocessing

DataLens provides automated insights into data quality, including:

- Missing-value detection and percentages
- Identification of columns requiring removal or imputation
- Basic preprocessing and data validation
- Numerical and categorical feature handling

### 📈 3. Exploratory Data Analysis

Perform exploratory analysis to understand patterns and relationships within the dataset.

- Summary statistics
- Numerical feature analysis
- Categorical feature analysis
- Correlation analysis
- Distribution analysis
- Relationship between variables

### 📉 4. Interactive Visualizations

DataLens includes reusable visualization functions for common EDA tasks:

- 📊 Bar plots
- 📈 Histograms
- 🔵 Scatter plots
- 📦 Box plots
- 🔥 Correlation heatmaps

These visualizations help users quickly identify distributions, correlations, trends, and potential outliers.

### 🤖 5. Machine Learning

The ML section provides a foundation for applying machine learning models to uploaded datasets.

The platform supports:

- Feature selection
- Target-variable selection
- Data preprocessing
- Model training
- Model evaluation
- Prediction
